# LazyVerticalGrid y LazyHorizontalGrid (Material 3)

> Aprende a crear cuadrículas (grids) con desplazamiento eficientes en Jetpack Compose con LazyVerticalGrid y LazyHorizontalGrid, usando componentes de Material 3.

*Básicos · Material 3*

## Composables de cuadrícula Lazy

Si necesitas mostrar muchos elementos en forma de cuadrícula, usar `Row` y `Column` anidadas compondría y colocaría todos los elementos, sean visibles o no. Las cuadrículas lazy de Compose solo componen y colocan los elementos visibles en el viewport del componente, igual que `LazyColumn` y `LazyRow`.

**LazyVerticalGrid**: genera una cuadrícula con desplazamiento vertical. El número y tamaño de las columnas se indica con el parámetro `columns`.  
**LazyHorizontalGrid**: genera una cuadrícula con desplazamiento horizontal. El número y tamaño de las filas se indica con el parámetro `rows`.

> *Para desarrolladores de Android (Views):* equivalen a un RecyclerView con `GridLayoutManager`, vertical u horizontal. La equivalencia es de uso, no de funcionamiento interno: no hay `Adapter` ni `ViewHolder`.

> **Sobre las librerías:** ambas pertenecen a Compose Foundation (`androidx.compose.foundation.lazy.grid`) y son independientes de Material. Los ejemplos usan además componentes de **Material 3** (`androidx.compose.material3`), como `Card` y `Text`.

## API de LazyVerticalGrid

Estos son los argumentos de la función `LazyVerticalGrid`:

```kotlin
@Composable
fun LazyVerticalGrid(
    columns: GridCells,                                     // Número y tamaño de las columnas (Fixed, Adaptive o FixedSize)
    modifier: Modifier = Modifier,                          // Modificadores de tamaño, padding, fondo, etc.
    state: LazyGridState = rememberLazyGridState(),         // Controla y observa el estado de la cuadrícula (posición del scroll)
    contentPadding: PaddingValues = PaddingValues(0.dp),    // Relleno alrededor de todo el contenido
    reverseLayout: Boolean = false,                         // Invierte el sentido del scroll y de la colocación de los elementos
    verticalArrangement: Arrangement.Vertical =
        if (!reverseLayout) Arrangement.Top else Arrangement.Bottom, // Cómo se colocan y separan las filas en vertical
    horizontalArrangement: Arrangement.Horizontal = Arrangement.Start, // Cómo se colocan y separan las columnas en horizontal
    flingBehavior: FlingBehavior = ScrollableDefaults.flingBehavior(), // Comportamiento del gesto de "lanzar" (fling)
    userScrollEnabled: Boolean = true,                      // Si es false, el usuario no puede hacer scroll (por código con state sí)
    overscrollEffect: OverscrollEffect? = rememberOverscrollEffect(),  // Efecto visual al llegar al final (null lo desactiva)
    content: LazyGridScope.() -> Unit                       // Define los elementos con item(), items()...
)
```

> El parámetro `overscrollEffect` solo existe en versiones recientes de Compose Foundation. Si tu versión no lo tiene, ignóralo.

## API de LazyHorizontalGrid

`LazyHorizontalGrid` tiene los mismos parámetros, cambiando `columns` por `rows` y los valores por defecto de las disposiciones:

```kotlin
@Composable
fun LazyHorizontalGrid(
    rows: GridCells,                                        // Número y tamaño de las filas (Fixed, Adaptive o FixedSize)
    modifier: Modifier = Modifier,                          // Modificadores de tamaño, padding, fondo, etc.
    state: LazyGridState = rememberLazyGridState(),         // Controla y observa el estado de la cuadrícula (posición del scroll)
    contentPadding: PaddingValues = PaddingValues(0.dp),    // Relleno alrededor de todo el contenido
    reverseLayout: Boolean = false,                         // Invierte el sentido del scroll y de la colocación de los elementos
    horizontalArrangement: Arrangement.Horizontal =
        if (!reverseLayout) Arrangement.Start else Arrangement.End, // Cómo se colocan y separan las columnas en horizontal
    verticalArrangement: Arrangement.Vertical = Arrangement.Top,    // Cómo se colocan y separan las filas en vertical
    flingBehavior: FlingBehavior = ScrollableDefaults.flingBehavior(), // Comportamiento del gesto de "lanzar" (fling)
    userScrollEnabled: Boolean = true,                      // Si es false, el usuario no puede hacer scroll (por código con state sí)
    overscrollEffect: OverscrollEffect? = rememberOverscrollEffect(),  // Efecto visual al llegar al final (null lo desactiva)
    content: LazyGridScope.() -> Unit                       // Define los elementos con item(), items()...
)
```

> `reverseLayout` no cambia el comportamiento de la disposición del eje principal: con `Arrangement.Top` (o `Start`) y `reverseLayout = true`, los elementos `123` pasan a mostrarse como `321` pegados al mismo extremo.

## GridCells: cómo se forman las columnas o filas

`GridCells` describe el número y el tamaño de las columnas en una cuadrícula vertical, o de las filas en una horizontal. Tiene tres variantes:

```kotlin
GridCells.Fixed(count: Int)       // Número fijo de columnas/filas, todas con el mismo tamaño (p. ej. Fixed(3) = 3 columnas de 1/3 del ancho)
GridCells.Adaptive(minSize: Dp)   // Tantas columnas/filas como quepan, cada una de al menos minSize; el espacio sobrante se reparte a partes iguales
GridCells.FixedSize(size: Dp)     // Tantas columnas/filas como quepan, cada una de exactamente size
```

## API de LazyGridScope: item, items e itemsIndexed

El parámetro `content` de las dos cuadrículas es un bloque `LazyGridScope.() -> Unit`. Dentro de él se añaden los elementos con estas funciones:

```kotlin
// Un único elemento
fun item(
    key: Any? = null,                                       // Clave estable y única del elemento (mantiene el scroll si cambia la lista)
    span: (LazyGridItemSpanScope.() -> GridItemSpan)? = null, // Cuántas columnas (o filas) ocupa el elemento
    contentType: Any? = null,                               // Tipo de contenido; los elementos del mismo tipo se reutilizan mejor
    content: @Composable LazyGridItemScope.() -> Unit       // Composable que dibuja el elemento
)

// Varios elementos a partir de un número
fun items(
    count: Int,                                             // Número de elementos
    key: ((index: Int) -> Any)? = null,                     // Clave estable y única para cada posición
    span: (LazyGridItemSpanScope.(index: Int) -> GridItemSpan)? = null, // Cuántas columnas (o filas) ocupa cada elemento
    contentType: (index: Int) -> Any? = { null },           // Tipo de contenido para cada posición
    itemContent: @Composable LazyGridItemScope.(index: Int) -> Unit // Composable que dibuja cada elemento
)

// Varios elementos a partir de una lista (requiere import androidx.compose.foundation.lazy.grid.items)
inline fun <T> LazyGridScope.items(
    items: List<T>,                                         // Lista de datos a mostrar
    noinline key: ((item: T) -> Any)? = null,               // Clave estable y única para cada dato
    noinline span: (LazyGridItemSpanScope.(item: T) -> GridItemSpan)? = null, // Cuántas columnas (o filas) ocupa cada dato
    noinline contentType: (item: T) -> Any? = { null },     // Tipo de contenido para cada dato
    crossinline itemContent: @Composable LazyGridItemScope.(item: T) -> Unit // Composable que dibuja cada elemento
)

// Igual que items(), pero también recibe el índice (requiere import androidx.compose.foundation.lazy.grid.itemsIndexed)
inline fun <T> LazyGridScope.itemsIndexed(
    items: List<T>,                                         // Lista de datos a mostrar
    noinline key: ((index: Int, item: T) -> Any)? = null,   // Clave estable y única para cada dato
    noinline span: (LazyGridItemSpanScope.(index: Int, item: T) -> GridItemSpan)? = null, // Cuántas columnas (o filas) ocupa cada dato
    noinline contentType: (index: Int, item: T) -> Any? = { _, _ -> null }, // Tipo de contenido para cada dato
    crossinline itemContent: @Composable LazyGridItemScope.(index: Int, item: T) -> Unit // Composable con índice y dato
)

// Tamaño (span) de un elemento
fun GridItemSpan(
    currentLineSpan: Int                                    // Número de columnas (grid vertical) o filas (grid horizontal) que ocupa, mínimo 1
)
```

> **Imports:** en las cuadrículas, `items` e `itemsIndexed` son funciones de extensión del paquete `grid`, **no** del paquete `lazy` de `LazyColumn`. Necesitas importar:
> `androidx.compose.foundation.lazy.grid.items`, `androidx.compose.foundation.lazy.grid.itemsIndexed` y, para los spans, `androidx.compose.foundation.lazy.grid.GridItemSpan`. Importar la versión equivocada es un error muy habitual.

Dentro de `span`, el `LazyGridItemSpanScope` expone `maxLineSpan`, el número máximo de columnas (o filas) de la línea. Es especialmente útil con `GridCells.Adaptive`, donde el número de columnas no es fijo.

## 1. Cuadrícula con columnas fijas

```kotlin
@Composable
fun FixedColumnsGrid() {
    LazyVerticalGrid(
        columns = GridCells.Fixed(2),
        modifier = Modifier.fillMaxSize()
    ) {
        items(20) { index ->
            Card(modifier = Modifier.padding(8.dp)) {
                Text(
                    text = "Item $index",
                    modifier = Modifier.padding(16.dp),
                    style = MaterialTheme.typography.titleMedium
                )
            }
        }
    }
}
```

- `GridCells.Fixed(2)`: la cuadrícula tiene siempre 2 columnas del mismo ancho, ocupando cada una la mitad del ancho disponible.
- `items(20)`: añade 20 elementos a partir de un número, con su índice.
- `Card` y `Text`: componentes de Material 3.

## 2. Cuadrícula adaptativa

```kotlin
@Composable
fun AdaptiveGrid() {
    LazyVerticalGrid(
        columns = GridCells.Adaptive(minSize = 128.dp),
        modifier = Modifier.fillMaxSize()
    ) {
        items(30) { index ->
            Card(modifier = Modifier.padding(8.dp)) {
                Text(
                    text = "Item $index",
                    modifier = Modifier.padding(16.dp)
                )
            }
        }
    }
}
```

Con `GridCells.Adaptive(minSize = 128.dp)`, cada columna mide al menos 128.dp y se crean tantas columnas como quepan. El espacio sobrante se reparte a partes iguales, así que en una pantalla estrecha verás pocas columnas y en una ancha (o en horizontal) verás más, sin cambiar el código.

## 3. Espaciado y content padding

```kotlin
@Composable
fun GridWithSpacing() {
    LazyVerticalGrid(
        columns = GridCells.Fixed(2),
        contentPadding = PaddingValues(horizontal = 16.dp, vertical = 8.dp),
        verticalArrangement = Arrangement.spacedBy(16.dp),
        horizontalArrangement = Arrangement.spacedBy(16.dp)
    ) {
        items(20) { index ->
            Card {
                Text(text = "Item $index", modifier = Modifier.padding(16.dp))
            }
        }
    }
}
```

- `contentPadding`: añade espacio alrededor de todo el contenido, pero la cuadrícula sigue haciendo scroll hasta los bordes del componente, sin recortar los elementos.
- `verticalArrangement = Arrangement.spacedBy(16.dp)`: separa las filas entre sí.
- `horizontalArrangement = Arrangement.spacedBy(16.dp)`: separa las columnas entre sí.

## 4. Elementos que ocupan varias columnas (span)

Un caso típico es una cabecera que ocupa toda la fila:

```kotlin
@Composable
fun GridWithHeader() {
    LazyVerticalGrid(columns = GridCells.Adaptive(minSize = 128.dp)) {
        item(span = { GridItemSpan(maxLineSpan) }) {
            Text(
                text = "Header",
                modifier = Modifier.padding(16.dp),
                style = MaterialTheme.typography.headlineSmall
            )
        }
        items(20) { index ->
            Card(modifier = Modifier.padding(8.dp)) {
                Text(text = "Item $index", modifier = Modifier.padding(16.dp))
            }
        }
    }
}
```

- `span = { GridItemSpan(maxLineSpan) }`: el elemento ocupa todas las columnas de la fila, sea cual sea su número. Por eso se usa `maxLineSpan` en lugar de un número fijo cuando la cuadrícula es adaptativa.
- `GridItemSpan(2)` haría que un elemento ocupe exactamente 2 columnas.

## 5. LazyHorizontalGrid

`LazyHorizontalGrid` se usa igual que `LazyVerticalGrid`, pero se desplaza en horizontal y se define con `rows`:

```kotlin
@Composable
fun SimpleHorizontalGrid() {
    LazyHorizontalGrid(
        rows = GridCells.Fixed(2),
        modifier = Modifier.height(200.dp),
        contentPadding = PaddingValues(horizontal = 16.dp),
        horizontalArrangement = Arrangement.spacedBy(8.dp),
        verticalArrangement = Arrangement.spacedBy(8.dp)
    ) {
        items(20) { index ->
            Card(modifier = Modifier.width(100.dp)) {
                Text(text = "Item $index", modifier = Modifier.padding(16.dp))
            }
        }
    }
}
```

- `rows = GridCells.Fixed(2)`: la cuadrícula tiene siempre 2 filas.
- `Modifier.height(200.dp)`: en una cuadrícula horizontal, la altura es el eje transversal y conviene acotarla; las filas se reparten ese espacio.
- `Modifier.width(100.dp)` en cada `Card`: da un ancho a cada celda para que el scroll horizontal tenga sentido.

> **Evita anidar** una cuadrícula vertical dentro de otro contenedor con scroll vertical (por ejemplo, un `Column` con `verticalScroll`): al no tener una altura acotada, Compose lanza una excepción. Usa una única `LazyVerticalGrid` y añade las demás secciones con `item(span = ...)`, o dale a la cuadrícula una altura fija.

## 6. Claves (key) y tipos de contenido (contentType)

```kotlin
data class Photo(val id: Int, val title: String)

@Composable
fun GridWithKeys(photos: List<Photo>) {
    LazyVerticalGrid(columns = GridCells.Fixed(3)) {
        items(
            items = photos,
            key = { photo -> photo.id },    // Clave estable y única de cada elemento
            contentType = { "photo" }       // Todos los elementos son del mismo tipo
        ) { photo ->
            Card(modifier = Modifier.padding(4.dp)) {
                Text(text = photo.title, modifier = Modifier.padding(8.dp))
            }
        }
    }
}
```

- `key`: por defecto, el estado de cada elemento se asocia a su posición. Con una clave estable, Compose mueve el estado junto con el elemento si cambia de posición y mantiene la posición del scroll. La clave debe ser única en toda la cuadrícula.
- `contentType`: indica el tipo de cada elemento; los de un mismo tipo se pueden reutilizar de forma más eficiente.

## 7. Controlar la posición del scroll (LazyGridState)

```kotlin
@Composable
fun GridScrollToTop() {
    val gridState = rememberLazyGridState()
    val scope = rememberCoroutineScope()

    Column {
        Button(onClick = {
            scope.launch { gridState.animateScrollToItem(0) }
        }) {
            Text("Ir al principio")
        }
        LazyVerticalGrid(
            columns = GridCells.Fixed(2),
            state = gridState
        ) {
            items(100) { index ->
                Text(text = "Item $index", modifier = Modifier.padding(16.dp))
            }
        }
    }
}
```

- `state`: el `LazyGridState` guarda la posición del scroll y te permite leerla u ordenar desplazamientos por código.
- `animateScrollToItem` / `scrollToItem`: son funciones `suspend`, por eso se llaman desde una corrutina (`rememberCoroutineScope`).
- `Button` y `Text`: componentes de Material 3.

> Si necesitas una cuadrícula con elementos de alturas distintas (estilo mosaico), Compose también ofrece `LazyVerticalStaggeredGrid` y `LazyHorizontalStaggeredGrid`, que usan `StaggeredGridCells` en lugar de `GridCells`.
